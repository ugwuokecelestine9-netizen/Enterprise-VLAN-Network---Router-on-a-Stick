# Lab 2– Enterprise Network Infrastructure

## Network Topology

This project implements an enterprise network using:

- Cisco 4331 Router
- Cisco ASA 5506-X Firewall
- Cisco 3560 Multilayer Switch
- Three Cisco 2960 Access Switches
- DHCP Server
- Multiple end-user devices

The multilayer switch provides the internal Layer 3 switching/routing
function, while the ASA provides the firewall/security boundary between
the internal network and the external router.

The access switches provide connectivity for end-user devices.
